# Foco Arrematações

Portal responsivo de apresentação e busca demonstrativa de leilões.

## Estrutura
- `index.html`: página principal, filtros e cards de demonstração.
- `logo.svg`: identidade visual vetorial.

## Publicação
Ative GitHub Pages nas configurações do repositório, usando a branch `main` e a pasta `/ (root)`.

## Importante
Os cards atuais são exemplos ilustrativos. O site ainda não está integrado a fontes externas de leilões, não consulta lotes reais e não processa lances. A integração com fontes, atualização de dados e validação dos anúncios é uma próxima etapa.
